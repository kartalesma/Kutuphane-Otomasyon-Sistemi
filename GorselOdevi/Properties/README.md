# 📚 Kütüphane Otomasyonu

Bu proje C# Windows Forms ve SQL Server LocalDB kullanılarak geliştirilmiş bir kütüphane otomasyon sistemidir.

---

# 🚀 Özellikler

- Kitap ekleme
- Üye ekleme
- Kitap ödünç alma
- Kitap listeleme
- Üye listeleme
- Geciken kitapları görüntüleme

---

# 🛠 Kullanılan Teknolojiler

- C#
- Windows Forms
- SQL Server LocalDB
- ADO.NET
- Visual Studio
